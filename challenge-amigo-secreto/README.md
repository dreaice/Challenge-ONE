#  📄 README - Proyecto "AmigoSecreto"

## 🎯 Descripción del proyecto
**Amigo Secreto** es una aplicación web sencilla que permite:
- Agregar nombres de participantes a una lista
- Visualizar todos los participantes registrados
- Seleccionar un ganador aleatorio para el juego de amigo secreto

## ✨ Características principales
- ✅ Interfaz intuitiva y fácil de usar
- ✅ Validación de campos vacíos
- ✅ Capacidad de agregar nombres presionando Enter o haciendo clic
- ✅ Visualización en tiempo real de la lista de participantes
- ✅ Selección aleatoria justa de un ganador

🚀 Cómo Usar la Aplicación
1. Agregar Participantes
- Escribe el nombre en el campo de texto
- Presiona Enter o haz clic en el botón "Añadir"
- Verás el nombre aparecer en la lista de participantes

2. Realizar el Sorteo
- Cuando hayas agregado todos los participantes:
- Haz clic en el botón "Sortear"
- ¡El nombre del ganador aparecerá en pantalla!
